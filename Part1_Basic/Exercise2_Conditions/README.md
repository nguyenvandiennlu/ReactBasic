# Bài 2: Câu lệnh điều kiện (Conditions)

## 1. Lý thuyết
Dùng để thực hiện các hành động khác nhau dựa trên các điều kiện khác nhau.

### Câu lệnh `if...else`
```javascript
if (điều_kiện) {
  // Thực thi nếu điều kiện đúng
} else {
  // Thực thi nếu điều kiện sai
}
```

### Câu lệnh `switch`
Dùng khi có nhiều nhánh rẽ cho cùng một biến.

## 2. Bài tập

### Yêu cầu 1: Chẵn lẻ
Kiểm tra một số bất kỳ xem nó là số chẵn hay lẻ.
*Gợi ý*: Số chẵn là số chia hết cho 2 (phần dư bằng 0). Toán tử chia lấy dư là `%`.

### Yêu cầu 2: Xếp loại học lực
Dựa vào điểm số để in ra xếp loại: Giỏi, Khá, Trung bình, Yếu.

## 3. Hướng dẫn chạy
```bash
node solution.js
```
