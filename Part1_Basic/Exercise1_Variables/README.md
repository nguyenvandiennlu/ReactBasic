# Bài 1: Biến và Kiểu dữ liệu

## 1. Lý thuyết cơ bản
Trong JavaScript (JS), chúng ta dùng biến để lưu trữ dữ liệu.
- `let`: Khai báo biến có thể thay đổi giá trị.
- `const`: Khai báo hằng số (không thể thay đổi sau khi gán).
- `var`: Cú pháp cũ, ít dùng hơn trong code hiện đại.

Các kiểu dữ liệu cơ bản:
- **String**: Chuỗi ký tự, ví dụ `"Hello"`, `'Vietnam'`.
- **Number**: Số, ví dụ `10`, `3.14`.
- **Boolean**: Đúng/Sai (`true`/`false`).

## 2. Bài tập

### Yêu cầu 1: Giới thiệu bản thân
Tạo các biến `name`, `age`, `address`, `hobby` và in ra một câu giới thiệu.

### Yêu cầu 2: Tính chỉ số BMI
Tính BMI theo công thức: $BMI = \frac{weight}{height^2}$

## 3. Hướng dẫn chạy code
Cài đặt [Node.js](https://nodejs.org/) nếu chưa có, sau đó mở terminal tại thư mục này và chạy:
```bash
node solution.js
```
