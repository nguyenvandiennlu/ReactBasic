# Bài 3: Vòng lặp (Loops)

## 1. Lý thuyết
Vòng lặp giúp thực hiện một đoạn code nhiều lần.

### Vòng lặp `for`
Dùng khi biết trước số lần lặp.
```javascript
for (let i = 0; i < 10; i++) {
  // Code chạy 10 lần
}
```

### Vòng lặp `while`
Dùng khi không biết trước số lần lặp, chạy miễn là điều kiện còn đúng.

## 2. Bài tập

### Yêu cầu 1: Đếm số
In ra các số từ 1 đến 100.

### Yêu cầu 2: Tính tổng
Tính tổng các số từ 1 đến `n` (ví dụ n = 100).
*Công thức toán học kiểm tra*: S = n*(n+1)/2

### Yêu cầu 3: Bảng cửu chương
In ra bảng cửu chương của một số (ví dụ bảng 7).

## 3. Chạy thử
```bash
node solution.js
```
